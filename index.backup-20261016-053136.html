A little about me

Build with care.
Learn in public.

I'm developing my skills by creating real projects, working through technical problems, and learning to document the decisions behind the code.

I value understandable systems, honest communication, maintainable foundations, and technology that serves people. I'd rather build the smallest useful thing well than add complexity just to make a project look impressive.

How I approach the work

  • Understand before changing Inspect the system and preserve what already works.
  • Make progress verifiable Use version control, testing, and clear checkpoints.
  • Document for the next person Make projects easier to understand, run, and maintain.
  • Stay honest about uncertainty Distinguish working features from plans and experiments.
